sources, with the same licenses and complete character coverage. Regenerate
with scripts/optimize-brand-fonts.py (FontTools with WOFF support).

The content-hashed files in subsets/ use the same licenses. Latin and extended
unicode-range subsets together preserve every supported Unicode character and
advance width from their TTF source. Layout features and glyph dependencies are
retained. Only the Latin subset is needed for ordinary English/French text.
