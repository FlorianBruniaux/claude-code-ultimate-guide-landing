Which keyboard shortcut interrupts the operation Claude is running, and exits Claude Code when pressed twice while nothing is running?

---

Ctrl+C interrupts a running operation, which is useful for stopping long-running analysis or when Claude is taking an approach you don't want. If nothing is running, the first press clears the prompt input and a second press exits Claude Code. Esc also interrupts Claude mid-turn but does not exit, and Ctrl+R searches command history. Knowing these shortcuts helps maintain control during your workflow.
