How do you toggle thinking on a model that allows it?

---

Alt+T (Option+T on macOS) toggles thinking where supported. Opus 5.5 and Fable always use thinking, so the toggle has no effect on those models. Choose a lower effort for bounded work instead. The ultrathink keyword adds a reasoning instruction without changing API effort; it is not a thinking toggle.
